# Enhanced Monthly Expense Tracker

## Description
A single-page web application designed to help users track their monthly expenses, visualize their total spending, and identify their top spending categories. This enhanced version builds upon a basic expense recorder by adding key analytical features.

## Features
*   **Add Expenses**: Easily input new expenses with details like date, category, amount, and an optional description.
*   **View All Expenses**: A clear table displays all recorded expenses, allowing for easy review.
*   **Total Monthly Expense**: A prominent display at the top of the page shows the calculated sum of all recorded expenses.
*   **Top 10 Category List**: A dedicated section lists the top 10 categories where money has been spent, sorted from highest to lowest amount. Categories are aggregated (case-insensitive) for accurate totals.
*   **Persistence**: All expenses are automatically saved in the browser's local storage, so your data remains even if you close and reopen the application.
*   **Delete Expense**: Individual expenses can be removed from the list.

## How to Run
1.  **Save Files**: Create a new directory and save `index.html`, `style.css`, and `script.js` into this directory.
2.  **Open in Browser**: Navigate to the directory and open `index.html` with your preferred web browser (e.g., Chrome, Firefox, Edge). The application will load instantly.

## Technologies Used
*   **HTML5**: For structuring the web page content.
*   **CSS3**: For styling the application to be visually appealing and user-friendly.
*   **JavaScript (ES6+)**: For implementing all interactive functionalities, data management (local storage), and calculations.
